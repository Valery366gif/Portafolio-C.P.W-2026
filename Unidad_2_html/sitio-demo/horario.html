Como entregar una practica

  1. Traer lo cambios con git pull
  2. Crear una rama para la practica con git switch -c "nombre de la rama"
  3. Trabajar y hacer un commit atómicos
  4. Subir la rama con git push
  5. Abrir un pull request en Github
  6. Revisar y fusionar la rama princupal (main)
  7. Eliminar la rama de la practica con git branch -d "nombre de la rama"

Glosario Git con listas de descriptivas

Commit

Rama
Línea de trabajo paralela que no afecta a main o rama principal
Pull
Solicitud de revisión para incorporar la rama
